## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach
The implementation swaps the first and last characters repeatedly until the middle is reached. This is an in-place reversal strategy that uses constant extra space.

### Complexity
- Time: O(n)
- Space: O(1)

### Notes
This technique is a classic two-pointer pattern and is useful when a string or array needs to be reversed efficiently without building a new structure.
