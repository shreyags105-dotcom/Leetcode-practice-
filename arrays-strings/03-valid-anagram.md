## Problem: Valid Anagram (Easy)

**Link:** https://leetcode.com/problems/valid-anagram/

### Approach
This solution compares the frequency of each character in both strings using a hash map. If the character counts match exactly, the strings are anagrams.

### Complexity
- Time: O(n)
- Space: O(k)

### Notes
The hash-based method is simple and robust, especially when handling repeated characters and edge cases such as empty strings.
