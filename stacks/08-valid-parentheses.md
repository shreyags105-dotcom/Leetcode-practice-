## Problem: Valid Parentheses (Easy)

**Link:** https://leetcode.com/problems/valid-parentheses/

### Approach
A stack is used to track opening brackets. Each closing bracket is matched to the most recent opening bracket, which ensures the sequence is balanced.

### Complexity
- Time: O(n)
- Space: O(n)

### Notes
This problem demonstrates why a stack is useful for nested structures such as parentheses, brackets, and braces.
