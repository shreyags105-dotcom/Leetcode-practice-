## Problem: Reverse a Linked List (Easy)

**Link:** https://leetcode.com/problems/reverse-linked-list/

### Approach
The function walks through the list while redirecting each node's next pointer to the previous node. This reuses the list structure while building the reversed order.

### Complexity
- Time: O(n)
- Space: O(1)

### Notes
This is a foundational linked-list problem and a good example of pointer manipulation in a linear data structure.
